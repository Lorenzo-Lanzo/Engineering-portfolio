Project overview

I developed a Eurorack carrier for the ADAU1701 audio SoM. The carrier adapts modular-synthesizer signals to the DSP core and provides the physical controls, connectors, and panel integration.

The supplied assembly and showcase footage follows a single module through to a compact case containing five modules.

Analog interface & packaging

Eurorack audio and control signals operate at levels different from the DSP converters. The carrier provides dedicated conditioning and protection stages between the patch connections and SoM.

The board and panel form a compact assembly, keeping the reusable digital core separate from the application-specific analog electronics and user interface.

Prototype state

The media documents assembled hardware, installation in a case, and power-on. These are useful milestones for mechanical and system integration. The module is presented as a DSP experimentation platform; numerical audio tests and algorithm source code are not included.
